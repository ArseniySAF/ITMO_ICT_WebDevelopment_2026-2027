## 1. Обмен сообщениями по UDP

Клиент отправляет серверу датаграмму `Hello, server` методом `sendto()`. Сервер получает сообщение методом `recvfrom()` и отправляет ответ `Hello, client` по адресу отправителя. UDP не устанавливает соединение и не гарантирует доставку, поэтому клиент ждёт ответа не более пяти секунд.

```python
# task_1/client.py
client.sendto(b"Hello, server", (args.host, args.port))
reply, _ = client.recvfrom(4096)

# task_1/server.py
message, client_address = server.recvfrom(4096)
server.sendto(b"Hello, client", client_address)
```

Пример вывода клиента: `Hello, client`. Сервер выводит адрес клиента и строку `Hello, server`.

## 2. Вычисление по TCP: теорема Пифагора

25-й номер = 1 вариант, так как варианты повторяются через четыре номера. Клиент запрашивает длины катетов `a` и `b`, затем отправляет их серверу как одну строку JSON. Сервер проверяет, что оба значения положительны и конечны, вычисляет гипотенузу по формуле `c = √(a² + b²)` и возвращает JSON-ответ. Для вычисления используется `math.hypot()`, который устойчивее прямого возведения больших чисел в квадрат.

TCP передаёт поток байтов. Завершающий перевод строки отделяет одно сообщение от другого; одного вызова `recv()` без правила разделения сообщений было бы недостаточно.

```python
# task_2/client.py
client.sendall((json.dumps({"a": a, "b": b}) + "\n").encode("utf-8"))

# task_2/server.py
request = json.loads(line)
result = {"hypotenuse": math.hypot(float(request["a"]), float(request["b"]))}
connection.sendall((json.dumps(result) + "\n").encode("utf-8"))
```

Пример работы:

```text
First leg a: 3
Second leg b: 4
Hypotenuse: 5
```

При нулевом, отрицательном или некорректном значении сервер возвращает сообщение об ошибке.

## 3. Раздача HTML-страницы по HTTP

Сервер принимает TCP-соединение, читает строку HTTP-запроса, загружает `task_3/index.html` из файла и формирует ответ со статусом `200 OK`. Заголовок `Content-Length` содержит длину **байтов** HTML после кодирования в UTF-8. Для неизвестного пути сервер возвращает `404`, для метода, отличного от GET, — `405`.

```python
# task_3/server.py
body = PAGE.read_bytes()
headers = (
    "HTTP/1.1 200 OK\r\n"
    "Content-Type: text/html; charset=utf-8\r\n"
    f"Content-Length: {len(body)}\r\n"
    "Connection: close\r\n\r\n"
)
connection.sendall(headers.encode("ascii") + body)
```

Проверка: при открытии `http://127.0.0.1:9003/` браузер показывает заголовок «Привет от сокетного HTTP-сервера!» и текст из `index.html`.

## 4. Многопользовательский TCP-чат

Сервер запускает отдельный поток для каждого TCP-подключения. Пользователь отправляет имя первой строкой; сервер проверяет его уникальность и сохраняет соединение в общем словаре. Сообщения рассылаются всем участникам, кроме отправителя. Блокировка защищает словарь от одновременного изменения, а отдельная блокировка на каждое соединение не позволяет потокам перемешивать отправляемые байты.

Один файл `task_4/client.py` запускается в нескольких терминалах с разными именами. Клиент получает сообщения в фоновом потоке, пока основной поток принимает ввод. Команда `/quit` закрывает участие в чате; сервер удаляет пользователя и сообщает остальным о выходе.

```python
# task_4/server.py
connection, address = server.accept()
threading.Thread(target=handle_client, args=(connection, address), daemon=True).start()

# В обработчике клиента:
clients[proposed_name] = (connection, send_lock)
broadcast(f"{name}: {message}", exclude=name)
```

Пример при двух запущенных клиентах:

```text
# Терминал Alice
OK Joined chat. Type /quit to leave.
* Bob joined the chat
Bob: Hello Alice
* Bob left the chat

# Терминал Bob
OK Joined chat. Type /quit to leave.
> Hello Alice
> /quit
```

## 5. Веб-сервер с GET и POST

Сервер вручную читает первую строку запроса, заголовки и тело согласно `Content-Length`. `GET /` и `GET /grades` возвращают HTML-страницу с формой и таблицей оценок. `POST /grades` принимает данные формы `application/x-www-form-urlencoded`, проверяет дисциплину и оценку от 2 до 5, добавляет оценку к списку соответствующей дисциплины и сохраняет словарь в `grades.json`. После записи сервер отвечает `303 See Other`, чтобы браузер перешёл на страницу журнала.

```python
# task_5/server.py
grades = load_grades()
grades.setdefault(subject, []).append(int(grade_text))
save_grades(grades)
result = response("303 See Other", b"", "Location: /\r\n")
```

Структура данных после двух POST-запросов для одного предмета:

```json
{
  "Математика": [4, 5]
}
```

В HTML выводится одна строка «Математика | 4, 5». Название предмета экранируется через `html.escape()` перед вставкой в страницу.
